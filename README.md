# Academic Portfolio — Md. Ismile Hossain Bhuiyan

A responsive single-page academic portfolio for GitHub Pages.

## Deploy
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `portrait.jpg`, `conference.jpg`, and `public-cv.docx` to the repository root.
3. Open **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish your website at `https://YOUR-USERNAME.github.io`.

## Customize
- Edit the About and project descriptions in `index.html`.
- Replace the photos with files of the same names.
- Update publications using the `pubs` JavaScript array embedded near the bottom of `index.html`.
- Add a LinkedIn URL when available.
- A simplified public-facing DOCX is included; replace with a formatted PDF if desired.

## Before publishing
Review the publications and DOI metadata for accuracy, including under-review status; the entries were extracted from the supplied CV and were not independently verified. The CV listed the same lumpy skin disease publication twice, which was consolidated. The public CV excludes the original CV’s personal-information and references sections.
